E-Commerce Analytics with Machine Learning

This project focuses on applying machine learning to real-world e-commerce data for predictive insights and decision-making support.
It combines data analytics, visualization, and modeling to analyze customer behavior, forecast sales, and identify key business drivers.

🔹 Objectives

Understand customer purchase behavior

Identify top-performing products and revenue sources

Predict future sales and customer churn

🔹 Approach

Data Preprocessing: Handled missing values, outliers, and categorical encoding

Exploratory Data Analysis (EDA): Visualized trends in customer and product segments

Feature Engineering: Created RFM (Recency, Frequency, Monetary) features

Modeling: Trained ML models (Random Forest, XGBoost, Logistic Regression)

Evaluation: Compared models using accuracy, precision, and recall metrics

🔹 Tech Stack

Languages: Python

Libraries: Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, XGBoost

Tools: Jupyter Notebook / Google Colab

🔹 Results

Improved prediction accuracy for customer purchase likelihood

Generated insights for targeted marketing and product strategy
